# Launchpad UX benchmark notes

These notes informed the site redesign. They are for internal product direction; public pages should not mention benchmarked competitors by name.

## Observed useful patterns

### Fast-launch boards

- Live trade activity ticker near the top of the app.
- Clear status tabs: launching, graduated, owned/created.
- Create-token CTA always visible.
- Chain/status filters, sort controls, and token search.
- Dense token cards with image, name, symbol, creator, age, description, tax badge, and graduation progress.
- Dark high-energy visual language with bright trading accents.

### Meme launchpad homepages

- Hero with clear value prop and CTA pair: launch + explore.
- Top-volume / trending mini leaderboard.
- Platform stats: volume, launched tokens, graduated tokens, highest mcap.
- Sort chips for last trade, newest, trending, market cap, volume, graduation.
- Cards communicate graduated state, social links, progress-to-graduation, creator, and volume.

### Consumer/social coin apps

- Persistent app-shell navigation.
- Top search with category chips.
- Image-first token grid.
- Create entry point always available.
- Detail pages combine chart, social context, holders, trades, and sticky trade panel.

## Adapted into our MVP

- Activity ticker in the hero proof board.
- Launch board filters for Launching / Newest / Near graduation / Graduated / No tax.
- Token cards with creator, social chips, status badges, progress, mcap, and volume.
- Sticky rounded nav and prominent Create Token CTA.
- Search-first board and category chips.
- Fast-scanning cards while keeping Cronos trust metadata visible.
- Token detail prototype with chart, trade panel, trades table, holders table, and trust signals.
- Create-token v2 mock with live preview, launch toggles, immutable-data warning, and preflight assessment.

## Cronos brand alignment

Cronos brand page exposes:

- Cronos Accent Blue: `#4CDBFF`
- White: `#FFFFFF`
- Black: `#000000`
- Dark surface + large rounded UI language
- bold lowercase Cronos wordmark energy
- circular token/brand mark with blue-on-black contrast
- Red Hat Display style typography

Adapted into our MVP:

- Core palette uses black/white/Cronos Accent Blue.
- Red Hat Display + monospace metric/address typography.
- Custom CSS brand orb motif instead of bundling official assets.
- Large dark rounded panels, cyan accents, high-contrast CTAs.
- Avoids implying official affiliation; this is a launchpad prototype aligned to Cronos aesthetics.

## Public-page rule

Do not reference internal competitors, benchmarks, or comparison products on public/demo pages. The public narrative should stand on Cronos Launchpad’s own product wedge:

- protected token identity
- anti-snipe launch windows
- VVS-compatible graduation
- public LP lock proof
- no-tax v0 default
- buyer-facing launch proof panels
