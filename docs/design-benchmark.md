# Launchpad UX benchmark notes

These notes informed the current site redesign.

## WolfSwap Launchpad

Useful patterns:

- Top activity ticker with recent buys.
- Clear state tabs: Launching, Graduated, Owned.
- Action cluster: Quick Buy, How it works, Create Token.
- Chain filter, activity sort, full-width token search.
- Dense token cards with image, name, symbol, creator, age, description, tax badge, and graduation progress bar.
- Dark green/teal liquidity aesthetic.

Adapted into our MVP:

- Activity ticker in the hero proof board.
- Launch board filters for Launching / Newest / Near graduation / Graduated / No tax.
- Token cards with creator, social chips, status badges, progress, mcap, and volume.

## Robinfun

Useful patterns:

- Strong hero with brand image, top-volume leaderboard, and chain stats.
- Explicit launchpad mechanics: start market cap, graduation market cap, LP burned/locked policy.
- CTA pair: Launch a Token + Explore.
- Sort chips: Last Trade, Livestream, Newest, Oldest, Trending, Highest MCap, ATH, Volume, Graduated.
- Cards communicate graduated state, social links, progress-to-graduation, creator, volume.

Adapted into our MVP:

- Hero stats for sample launches, progress, and LP lock default.
- Deployment/testnet readiness section showing the path to real addresses.
- Launch cards include graduated / near-graduation states.

## Pump.fun

Useful patterns:

- App-shell feel with persistent nav, search, category chips, and create CTA.
- Big image-first token grid for discovery.
- Sections for trending/top items before the full board.
- Simple create/sign-in entry points.

Adapted into our MVP:

- Sticky rounded nav, prominent Create Token CTA.
- Search-first board and category chips.
- Fast-scanning cards while keeping Cronos trust metadata visible.

## Cronos brand alignment

Cronos brand page exposes:

- Cronos Accent Blue: `#4CDBFF`
- White: `#FFFFFF`
- Black: `#000000`
- Dark surface + large rounded UI language
- bold lowercase Cronos wordmark energy
- circular token/brand mark with blue-on-black contrast

Adapted into our MVP:

- Core palette uses black/white/Cronos Accent Blue.
- Custom CSS brand orb motif instead of bundling official assets.
- Large dark rounded panels, cyan accents, high-contrast CTAs.
- Avoids implying official affiliation; this is a launchpad prototype aligned to Cronos aesthetics.
